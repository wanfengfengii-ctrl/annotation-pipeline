# Mac Terminal 作业流程

参考 [Mac 文档](https://docs.qq.com/document/DVVdadUV2dWV4UXZX)，按用户 2026-09-09 最新规则执行。模型、网关和 1000000 上下文保持原配置。

- 可见 Mac Terminal 启动镜像中的交互式 Claude，Runner 经终端输入题目。Codex 出题、骨架和评分阶段不调用 Claude CLI。保存实际 TTY、终端标识及原始 CLI 版本和会话 ID。
- 0-1、Feature、代码理解、代码重构每题使用新 Terminal 会话、新容器和完全空的工作区。启动后再安装骨架或导入上题冻结代码。只挂载 /workspace，保留固定镜像、非 root、cap-drop ALL、no-new-privileges 和隔离配置。
- 首题由 Codex 提前生成最小骨架、入口和通用配置，不实现被测业务功能。0-1 包括同项目此前不存在的全新功能，Feature 是已有功能的改进。两类每项目各最多十题，失败或排除仍占已分配题额。
- 目标比例为 7:7:10:1:1，按跨项目累计有效记录及在途任务调度。Bug 必须有真实依据，只在当前会话追问，最多两轮，即初始题加修复共三条对话。每会话另有十次实际调用硬上限，重试不释放。
- Bug 追问使用平淡、口语化的一段具体问题，说明已观察到的现象和预期，不使用引号、可能、竟然等措辞，不编造人工经历。普通截断不自动续写，也不改成 Bug 凑数。
- 新题切换、会话完成或上限达到后，通过两次 Ctrl-D 结束。完整复制 /home/node/.claude/projects 并核验哈希后才删除容器；失败则保留容器。Runner 重启可重连存活的 Terminal 控制通道，不重新启动或 resume 旧 Claude。
- 预检免审批模式、六种工具及工作区写权限；轨迹出现权限拒绝或缺少实际终端来源时，保留原始内容并阻止合格导出。同题后续权限异常也会阻止此前记录和旧批次下载。
- Docker 当前约 7.7 GiB，预留 2 GiB，每容器 3 GiB/2 核，实际并发 1。并行任务各使用独立 Terminal 和容器。

骨架和初始代码随证据包冻结，依赖、缓存与敏感配置按清单排除。代码及原始轨迹留在本机，云端队列与本地队列独立。保留 AI 评分来源、人工末尾二次确认、30 列 Excel、分页及导出次数。
