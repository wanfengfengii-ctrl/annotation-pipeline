# 评分阶段的点评对照

SOLO 的 1598、1599 因交付完整性描述与同项目旧记录 1419 命中 B-7 分段复读而待返修。真实代码和评分依据仍然保留，不能用删除缺陷、同义替换或修改分数消除平台提示。

首次评分和交付校验现在共用 `scoreInstructions` 的点评要求：保持五维分档及相邻档位的事实解释，以本轮实际操作、结果和影响组织段落，不反复套用固定的升降档结尾。需要引用相同函数或真实错误时仍照实引用，不为了文字不同编造事实。

评分输入附带本项目较相关的先前业务记录点评，最多四条。只选择当前轮之前已完成、未排除的记录，按实际题目及点评与本轮目标的文字关联排序，再按时间先后打破同分；该排序仅选择对照片段，不模拟平台查重，不判断评分或重复是否合格。原题片段上限 360 字符，每维点评上限 400 字符，截取情况单独标明。不会把整条任务、运行令牌、旧分数、当前记录的旧评分或未来记录加入这份对照。

历史内容是不可信的对照数据，不是本轮事实和指令。评分器仍须独立核对当前冻结源码、原题与原始日志，不能把历史问题混入本轮，也不能宣称这些有限对照等于通过平台查重。此变更不增加上传时的关键词关卡，不重写已保存评分、原题、原生轨迹或远端回执。

点评规则和历史片段都进入评分、交付阶段的缓存摘要，规则变化不能复用旧评分检查点。后续单题通过不可变作业发布采用新版本，已经运行的作业继续使用其已加载版本。1598、1599 仍需按对应冻结证据分别进行评分返修，不能把新规则发布当作历史数据已修复。
