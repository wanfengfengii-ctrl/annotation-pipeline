# 标注流水线

独立工作台：任务创建 → 初始 Git 快照 → Claude CLI 顺序执行 → 原始交互留档 → 人工五维评分 → 形式校验 → CSV 导出 → 人工登记实际提交。

## 本机使用

需要 Node.js 22.13+、Git、已完成配置与登录的 `claude` CLI。

```sh
npm install
# 首次初始化数据库，已经初始化的环境无需重跑
npm run db:local
# 首次使用时创建本机执行器密钥（不要提交 .dev.vars）
node scripts/init-local.mjs
npm run dev
# 在另一个终端启动执行器
npm run runner
```

打开 http://localhost:3000。CLI 不传入 `--model`、`--settings` 或权限覆盖参数，继承用户配置。原项目已提交的 `.claude` 配置会包含在独立工作区中，`.claude/settings.local.json` 会仅在本机复制到工作区。不会自动绕过 CLI 权限；缺少权限时在原始记录中保留失败。

为任务填写本机 Git 仓库绝对路径、语言框架、题型与难度。输入 Prompt 后才会执行；创建任务本身不会调用模型。初始仓库必须干净，origin 为 GitHub 且 HEAD 已存在于 origin 远端历史。执行器只 fetch 和创建 detached worktree，不自动 commit/push 用户代码。评测团队的仓库访问权限仍需人工确认。

每个任务在 `.runner/<task-id>/workspace` 下有独立工作区。后续轮次通过 `--resume` 恢复该任务的 Claude 会话。原始 stream-json、stderr、原生会话轨迹副本与回写记录保存在 `.runner/<task-id>/`；不会进入 Git 或发布包。页面输出最多显示 100,000 字符，完整内容保留本地轨迹。

## 边界

- 首轮不能是简单题，有效交互最多 10 轮。模型执行结束只意味着进程完成，不代表需求完成。
- 五项人工评分与描述均必填；人工确认看过产物和轨迹后才能导出。形式校验不进行语义判断、不代写反馈、不代表项目验收通过。
- 网络、工程失败仍保留；人工判断有反馈价值可进入评分，否则填写具体原因排除。CLI 输出中的消息 ID 必须从真实用户消息获得，缺失时阻止交付并允许人工从轨迹补录。
- “导出”和“提交”分离：CSV 不改变状态；填写实际外部提交回执后锁定该轮。不会自动向腾讯文档写数据。
- 截止时间按 Asia/Shanghai：20:00 前当日结束前提交，20:00 起次日 14:00 前。
- 示例接口测试数据标明为 synthetic，验证后删除；不生成正式评分数据。
- 技术栈/任务相似性、描述质量、每日分布偏序由人工核查。统计只辅助检查，不伪造精确比例要求。

## 执行器运维

默认一个串行执行器，不启动无限重试的模型调用。默认每轮最长 30 分钟，`RUNNER_TIMEOUT_MS` 可调整；超时先终止再强制退出。网络回写失败会重试，结果保存在磁盘。重启会先补交已完成结果，不重新调用模型。

`.runner/runner.lock` 防止误启动第二个执行器。如果进程异常退出残留锁，确认该 PID 已停止后删除锁再启动。若进程在产生结果前崩溃，该轮保留 running 状态以避免重复执行，应由运维确认进程已退出后恢复；当前版本不自动重放不确定结果。

## 本机与云端

云端版本具有独立 D1 数据库，与本机数据库不自动同步。私有云端页面用于远程管理时，还需配置执行器认证及 Sites 站点访问凭据。未连接前云端显示执行器离线，队列不会执行。本机版本不依赖云端，可直接调用本机已配置 CLI。

自托管 API 可设置 `PIPELINE_API_URL` 与 `RUNNER_TOKEN`；令牌只用于执行器，不能放入浏览器。不要公开无需认证的本机开发服务。

## 验证

```sh
node --experimental-strip-types --test tests/rules.test.mjs
npx tsc --noEmit
npm run build
```

`tests/api.test.mjs` 是本机集成测试，运行前停掉执行器，运行后按 `.runner/api-test-id` 清理自己创建的测试任务。覆盖并发版本冲突、执行凭据校验、10 轮上限、评分门禁、提交锁定、CSV 过滤。
